# 판단 유니버스

내 판단을 기록하고 채점하는 주식 판단 연습장. 실제 주문 기능은 없음.

- 화면 : `index.html` `core.js` `ui.js` (깃허브 페이지) — 환경(거시 위험 점수 · 이슈 · 일정) / 종목 / 유니버스(가상 매매) / 기록
- 자동 수집 : `bot/bot.py` 를 깃허브 액션이 실행 (`.github/workflows`)
  - 5분 점검 : 현재가, 가격 알림, 장중 ±5% · ±10% 급등락, DART 공시, 새 종목 10년 이력, (매시) 컨센서스 · 실적 · 기사 번역
  - 장 마감 정리 : 일봉 보충, 이슈 · 시장 요약 · 일정, 급등락 사유 분석 (Groq)
- 가지 : `main` 화면 · 봇 · 정적 시세 / `live` 봇 출력 (매번 덮어씀) / `state` 내 기록 (모니터링 목록 · 가상 매매 · 메모)
- 비밀 값 (Settings › Secrets and variables › Actions) : `GROQ_API_KEY` `DART_API_KEY` `NTFY_TOPIC` — 코드에는 넣지 않음
- 시세 출처 : 야후 · 나스닥 · 네이버 금융 (무료, 지연 가능). 매수 타점 점수는 10년 백테스트 기준 참고 지표이며 수익을 보장하지 않음.
